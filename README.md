# 基于 PH1P35 FPGA 的实时视觉与标记化安防系统

全国大学生嵌入式芯片与系统设计竞赛 2026 FPGA 赛道，安路赛题二主工程。

系统采用 HX1P35A 开发板，主器件为 **PH1P35MDG324，速度等级 -3**。SC500CS 摄像头经 MIPI 接入，FPGA 完成图像处理、DDR2 帧缓存、检测跟踪和 HDMI 显示，并控制双轴舵机与蜂鸣器。设计不使用外部处理器，也不使用器件内的 MCU；所有功能集成于同一比特流。

## 功能

- 1280×720、60 Hz HDMI 输出，叠加安路 Logo、检测框及状态信息。
- 八种显示模式：直通、灰度、二值化、Sobel 边缘、边缘二值、卡通化、反色和直方图均衡。
- 黑电平校正、Bayer 去马赛克、AWB、Gamma、自动曝光及手动数字增益；统计页显示 RAW/RGB 与亮度分布、曝光和增益。
- 红、绿、蓝三色与圆形、方形、三角形标记检测，最多输出九个候选目标；依据颜色、形状、位置和尺寸进行跨帧关联，并通过双轴舵机跟踪选中目标。
- 以颜色表示权限、形状模拟对象类别的区域安防演示；支持区域判定、连续结果确认、事件记录、蜂鸣提示、告警跟踪、确认回正和离场后重新布防。该功能识别的是几何颜色标记。

## 按键

- **K1**：循环切换八种显示模式。
- **K2**：进入或退出检测与跟踪页面。
- **K3**：进入或退出安防应用页面。
- **K4 / K9**：增加 / 减少数字增益。
- **K5**：在检测与跟踪页面切换目标。
- **K6**：进入或退出统计页面。
- **K7**：开关自动曝光。
- **K8**：确认安防事件，停止报警并使云台回正，等待触发目标离场。
- **K10**：开关自动白平衡。

## 打开与构建

推荐使用工程记录的 **Tang Dynasty 6.2.168116** 及 PH1P35 器件支持包。下载或解压后保持目录结构，先在工程根目录运行：

```powershell
& ./verify_package.ps1
& ./prepare_project.ps1
```

然后在 TD 中打开 `td_project/camera_to_dsi_display.al`。`prepare_project.ps1` 仅更新本机工程目录字段，不修改 RTL、约束或综合布局布线策略。校验脚本允许该目录字段随本机位置变化。

批量完整构建可执行以下命令，将工具路径替换为实际安装路径：

```powershell
& 'D:/Anlogic/TD_6.2.1_Engineer_6.2.168.116/bin/td_commands_prompt.exe' 'rebuild_check.tcl'
```

该命令会重新综合和布局布线。工程保留原有实现设置；脚本检查最终 Setup/Hold 裕量，出现负裕量会报告构建检查失败，即使工具已经生成 bit。

## 功能仿真

仿真需要 ModelSim 和 TD 提供的 PH1P 仿真原语库。指定本机工具目录后执行：

```powershell
& ./sim/run_tests.ps1 -ModelSimBin 'D:/modelsim/win64' -TDHome 'D:/Anlogic/TD_6.2.1_Engineer_6.2.168.116'
```

脚本从主工程及 IP 配置读取源文件，编译完整生产层次，并运行按键、图形检测、跟踪、舵机、安防和图像处理功能测试。工具输出写入被忽略的 `sim/_work/`。功能仿真不等同于布局布线时序验证或硬件实测。

仅检查编译时，在上述命令末尾添加 `-CompileOnly`。本次整理已完成 108 个生产 RTL/IP 文件和 24 个测试文件的编译检查，均无编译错误；本机 ModelSim 仿真许可证不可用，因此没有重新完成顶层展开和功能仿真运行。

## 硬件使用

摄像头和 HDMI 使用板载对应接口；按键板、蜂鸣器和双轴舵机接线以 `user_source/constraints_source/pin.adc` 及实际装机为准。舵机使用独立的合适电源，并与 FPGA 开发板共地。Flash 下载使用 TD 配套工具及对应板卡配置；确认器件、下载文件及外设接线后操作。
